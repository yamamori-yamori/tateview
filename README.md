# 日本語縦書き小説viewer / 校正用ツール　縦view

小説を公募に出す前に、縦書きで読んだり校正したりするためのツールです。  

- 作者: [やまもりやもり](https://yamamori-yamori.github.io/mypage/)

- 外部サーバー・CDN不要。完全ローカルHTML。
- ブラウザでHTMLファイルを開くだけで動作します。Windows / macなどプラットフォームを問いません。
- 日本語長編小説を前提に設計されています。10万文字超えていても快適に動作します。

---

## 使い方

1. [こちら](https://github.com/yamamori-yamori/tateview/raw/refs/heads/main/TateView.zip)をダウンロードしてzipを解凍し、`TateView.html` をブラウザで開く（Chrome / Edge / Firefox 推奨）。
   または、 [作者HP](https://yamamori-yamori.github.io/mypage/)から「WEB版」をご使用ください。
2. 左上の「開く」でテキストファイルを指定してください。ドラッグアンドドロップも出来ます。
3. 右上側で原稿用紙のフォーマットを設定できます。
4. ←→キー、スペース（shiftスペース）、またはマウスホイールでスクロールします。
5. 左下で表示の各種設定ができます。禁則処理や追い出しも対応。罫線も入れられます。
6. 左上で章や話の記号を設定すると、サムネにも表示されます（デフォルトでは`#`および`##`)
7. 右上の「校正」ボタンを押すと、右側に校正ワーニングが開きます。「字下げがない、カッコが閉じていない、？の後ろに空白がない、…が奇数」などのワーニングが表示されます（校正ワーニング一覧ファイルを参照してください）
8. 上の検索窓にワードを入力するとそのワードがハイライトされ、全文中の件数が表示されます。
9. このビュアーに編集モードはないですが、**裏でエディタなどでテキストを修正すると自動的に読み込んで更新**されます(safariでは自動更新ができません。chromeなどをご使用ください）
