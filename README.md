# 日本語縦書き小説viewer / 校正用ツール　縦view v1.0

小説を公募に出す前に、縦書きで読んだり校正したりするためのツールです。  

- 作者: [やまもりやもり](https://yamamori-yamori.github.io/mypage/)

- 外部サーバー・CDN不要。完全ローカルHTML。
- ブラウザでHTMLファイルを開くだけで動作します。Windows / macなどプラットフォームを問いません。
- 日本語長編小説を前提に設計されています。10万文字超えていても快適に動作します。

---

## 使い方

1. [こちら](https://github.com/yamamori-yamori/tateview/raw/refs/heads/main/TateView.zip)からzipをダウンロードして解凍。`TateView.html` をブラウザで開く（Chrome / Edge / Firefox 推奨）
2. 上側で原稿用紙のフォーマットを設定できます。
3. 左側で表示の各種設定ができます。小説中の章や話の記号を設定するとサムネにも表示されます（デフォルトでは`#`および`##`)
4. 上の「校正」ボタンを押すと、右側に校正ワーニングが開きます。「字下げがない、カッコが閉じていない、？の後ろに空白がない」などのワーニングが表示されます。
